# SalaryCalc · 薪资个税计算器

> 💰 五险一金明细 · 累计预扣个税 · 税前税后互算 · 年终奖两种计税对比 —— 纯前端本地计算，**输入不保存、不上传**。

**在线使用 → <https://salary.adcakeyuan.top>**

## 功能

- **税前 → 税后**：输入税前月薪，逐项列出五险一金个人缴纳明细（缴费基数、比例可调），按年度综合所得税率表计算个税，得出税后月薪
- **税后 → 税前**：反向二分推算达到目标到手金额所需的税前月薪
- **年终奖对比**：单独计税（按月换算税率表）与并入综合所得两种方式逐一计算，自动标出更优方案与差额（单独计税政策延续至 2027 年底）
- **全年总览**：年收入、扣除项、个税、年终奖到手、全年总到手一览
- **单位部分**：可展开查看单位缴纳的五险一金金额与企业用工成本
- **可调参数**：公积金比例、社保缴费基数及上下限、专项附加扣除、各险种个人/单位比例均可修改，适配不同城市政策

## 特点

- **零上传**：所有计算在浏览器本地完成，无后端、无存储
- **零依赖**：原生 HTML / CSS / JavaScript，无需联网即可使用
- **透明**：计算所用的两张税率表直接展示在页面底部，每一步扣除项都有明细

## 本地运行

无需构建，直接打开 `index.html` 即可。

## 部署

静态站点，推送 GitHub 后由 **GitHub Pages** 托管，自定义域 `salary.adcakeyuan.top`（CNAME 文件 + Cloudflare DNS）。
